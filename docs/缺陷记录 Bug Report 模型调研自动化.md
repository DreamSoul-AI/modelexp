# 当前已知问题

历史表有模型/制品 revision 缺失，影响唯一身份核对；校验会列出具体记录。量化 CSV 的名称关联、长文本效果说明与线上类型不一致，目前两列暂不自动映射。缺当日文件不会用旧日期冒充交付。

## 评分依据

旧标化值无法全部按同一套参考集合重现。经用户授权，建立 v0.3 冻结参考并统一重算；旧快照保留。来源中的不同工具、预算和评测版本仍影响可比性，冻结百分位仅用于初筛。来源不可访问、没有本配置证据或新 Benchmark 未映射时保留问题候选。

## 运行边界

额度查询失败保守暂停模型调用，达到配置阈值或日调用预算也暂停。认证失效、网络故障和未知提交分别记录；不会通过重建记录或更换身份绕过。尚无自动通知，也不输出每日变更摘要。
