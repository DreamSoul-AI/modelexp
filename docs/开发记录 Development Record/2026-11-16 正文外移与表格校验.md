# 正文外移与表格校验

## 当前要求与结果

用户将 Markdown 正文编写交给 Grokbot，要求移除 Codex 正文生成和研究队列，将第二项任务改为不调用模型的字段规则与 CSV/线上表格逐项校验。校验仅报告问题，不自动修表，不核实参数、许可、量化效果或评测成绩的事实真实性。

已导出123份已有正文及来源，122份标记researched、1份needs_review；压缩包校验通过。未形成正文的输入模板不导出，包中不含凭据、数据库、原CSV和人工笔记。Grokbot提示词见[交接文件](../../skills/model-research/assets/grokbot-md-prompt.txt)。

## 实现

- 移除 agent_runner.py、codex_agent.py、research_pipeline.py、sources.py 及对应旧生成/队列测试；CLI/service不再提供research模式，旧agent.command/enabled=true配置明确失败。
- 移除候选导入的正文生成/覆盖路径；dossiers正文候选被拒绝。保留CSV内部元信息、人工保护、结构化字段证据导入及历史export-md/finalize-md迁移能力。
- 增加validation.py及validate CLI/service模式。只读检查所有配置表的映射schema、字段值、身份完整性、重复identity/record_id，逐项比较当前CSV，记录漏项、差异、映射改变与冲突。
- 以只读SQLite及旧dossier元信息识别受保护人工修订；不推进同步基线。历史行没有当日CSV不作漏项；公式、人工及未归属字段不强制跟随CSV。
- 校验保存读取快照、逐表覆盖、JSON和问题CSV；严重性info/warning/error明确分开，错误/警告返回partial，输入缺失、schema变化或无法读取不能报全表通过。
- CSV与validate使用独立state与锁，均北京时间12:00开始、18:00前检查。旧AI服务停用并屏蔽，历史研究state离线归档，不再调度。

## 验证

新校验针对性测试10项通过；调整后全部本地回归107项通过，无跳过和未完成项。最终去重提示改动及历史导出清理后，校验11项和导出8项相关测试再次通过。覆盖只读边界、漏同步、历史行、重复身份、字段变化、非法枚举、人工镜像、坏CSV的部分报告及旧模型配置拒绝；原CSV增量写回、回执丢失恢复与Markdown历史导出回归保留。

服务器已安装新固定版本，并按最近已交付的2026-11-15业务日完成两次真实只读校验及稳定观察；107行匹配，1351项受控值一致，四表1304行发现17条缺版本警告。详情见[运行记录](<../运行记录 Run Record/2026-11-16 表格校验上线.md>)，不把字段一致说成全表事实正确。

## 边界

不做模型调用、正文研究、量化制品发现或事实真伪核验；不自动修复线上问题，不改评分/公式，不清空历史数据。当前未新增自动失败通知。私有交付包在仓库外保存，不纳入Git；源代码提交与推送状态以Git历史及远端为准。
