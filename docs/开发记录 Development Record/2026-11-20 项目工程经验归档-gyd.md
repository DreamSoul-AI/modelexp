# 模型资料维护工程经验

## 文件与身份

同名 CSV 可被替换，必须保存内容哈希和来源版本。上游 ID 可被重编，内部身份应使用 URL、revision 和必要的模型配置，不能仅按名称或旧 record_id 匹配。CSV 缺行不等于远端应该删除。

## 官方 CLI 的读取边界

NDJSON 返回 manifest，不能按普通 ok 信封解析。既要检查文件行数和分页，也要检查 rev；官方单次最多50个字段，宽表需要多投影并验证一致。schema 指纹忽略显示顺序与颜色，保留类型、名称、选项与公式语义。

## 写回与恢复

人工保护依赖源值、线上值和已验证基线的三方比较。发出请求但丢失确认必须先对账；新的操作ID也不能绕过同实体未知提交。凭据目录可写、网页授权成功、CLI登录成功与实际模型调用是不同的验证点。

## 评分与证据

不能从无法重现的历史标化值倒推出唯一算法；新版本应冻结原始参考样本、计算规则和指纹，备份后显式迁移。模型回答必须引用实际读取的本实体材料，并说明 Benchmark 版本及配置；相同来源不必每日重复消耗模型额度。百分位无法消除不同评测协议的差异。
